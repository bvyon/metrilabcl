# Cuatro variaciones de logo

Generadas con la herramienta integrada de imagegen el 10 de octubre de 2026, usando como referencia el búho proporcionado por el propietario. Son propuestas PNG para elegir una dirección visual. La tipografía se aproxima visualmente a DM Sans y Newsreader; la versión para el sitio deberá usar las fuentes reales y un símbolo limpio en SVG.

1. `01-azul-horizontal.png`: composición para cabecera; azul original y sans-serif.
2. `02-verde-editorial.png`: verde de la web y serif editorial; opción recomendada para la identidad del sitio.
3. `03-azul-apilado.png`: composición vertical; azul original y serif editorial.
4. `04-monocromatico.png`: marfil sobre verde oscuro; composición horizontal a una tinta.

Estas propuestas no sustituyen todavía la marca publicada.
